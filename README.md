# OUAK Mods hub

The website and releases of the OUAK mods for *Once Upon a KATAMARI*: https://nmlacker.github.io/OUAK-hub/

- The mods, their source and their **releases** are in [nmlacker/OUAK-Mods](https://github.com/nmlacker/OUAK-Mods): each release holds `OUAK_Mods.zip` (the OUAK Modding API, Mod Menu and Multiplayer), and the API installs new releases from there by itself.
- The site is plain HTML (`index.html`, `mods.html`: the modpack and each mod with its release and source, `faq.html`, `docs.html`); the docs are copies of the mods' READMEs in `docs/`.

An unofficial fan project, not affiliated with or endorsed by Bandai Namco Entertainment.
