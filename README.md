# OUAK Mods hub

The website and releases of the OUAK mods for *Once Upon a KATAMARI*: https://nmlacker.github.io/OUAK-hub/

- **Releases** hold `OUAK_Mods.zip` (the OUAK Modding API, Mod Menu and Multiplayer) and `OUAK_Mods_Source.zip`. The OUAK Modding API installs new releases from here by itself.
- The site is plain HTML (`index.html`, `faq.html`, `docs.html`); the docs are copies of the mods' READMEs in `docs/`.

An unofficial fan project, not affiliated with or endorsed by Bandai Namco Entertainment.
