What's inside

REQUIRED

OUAK Modding API

The shared base every mod uses: the mod window, hotkeys, game events, stages and modes, saves, logging, asset replacement and hot mods. It also patches broken and unused parts of the game, like the Race and Target modes, King Chances, unlimited dash and the unfinished freebies. Updates itself automatically.

MOD

OUAK Mod Menu

Single-player tools for speedrunning, TASing and messing around: freebies, the stage clock, stages and modes, unlocks, and save backups.

MOD

OUAK Multiplayer

Play the story stages online together, plus Katamari Ball against CPU princes with custom rules, King Chances, Race and Target.

Standalone mods

Separate from the download above; not released yet.

STANDALONE

OUAK Song Selector

Playlists of the game's music and your own songs (MP3, FLAC, M4A, WMA, WAV and more), updated as you add files, with play, pause, next, previous, loop and shuffle.

STANDALONE

OUAK Dash Bar

Shows how much dash you have left on the game's own unused dash gauge, and how long until it comes back.

Install

  1. Install MelonLoader 0.7 into your Once Upon a KATAMARI folder (Steam: right-click the game › Manage › Browse local files) and start the game once.
  2. Download the mods and unzip them into the same folder, so Mods and UserLibs merge with the ones MelonLoader made.
  3. Start the game and press Right Shift for the mod window.

The download holds the API, the Mod Menu and Multiplayer. The API is required; the others are optional and each needs only the API. For online play, everyone needs the same version: the API keeps you up to date by itself and asks you to restart when an update is installed.
