Install

  1. Install MelonLoader 0.7 into your Once Upon a KATAMARI folder (Steam: right-click the game › Manage › Browse local files) and start the game once.
  2. Download the OUAK Modpack and unzip it into the same folder, so Mods and UserLibs merge with the ones MelonLoader made.
  3. Start the game and press Right Shift for the mod window.

The modpack holds the API, the Mod Menu, Multiplayer and the Dash Bar. The API is required; the others are optional and each needs only the API. For online play, everyone needs the same version: the API keeps you up to date by itself and asks you to restart when an update is installed.
