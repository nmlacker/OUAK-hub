Frequently asked questions

What do I need?

Once Upon a KATAMARI on Windows (Steam) and MelonLoader 0.7. The mods are made for the game as it is on Steam; a game update can break them until the mods are updated.

Which mods do I need?

The OUAK Modding API always; it's what the other mods are built on. The download also holds the Mod Menu and Multiplayer; Song Selector and Dash Bar are standalone mods, released separately. None of them needs another, only the API.

How do I open the mod window?

Press Right Shift in game. Every installed mod adds its tabs to that one window. You can rebind the key in its Keys tab, and a controller can move through it too.

How do updates work?

The API checks for a new release each time the game starts and installs it in the background. Once it has, a message asks you to restart the game or quit, and the new version runs from the next start. To turn automatic updates off, set AutoUpdate = false under [OUAKModAPI] in UserData/MelonPreferences.cfg.

Can I play online with friends?

Yes, with OUAK Multiplayer: host or join from its Online tab in the mod window. Everyone in a session needs the same version, which automatic updates take care of.

Will the mods change my save?

The API on its own doesn't change how the game plays, apart from fixing bugs in the game's own Katamari Ball. Its fixes for unfinished features only act when a mod uses them. The Mod Menu can change your save (unlocks, for example) and makes backups you can restore from its window. Back up your save before trying anything big.

How do I add my own music?

With OUAK Song Selector, a standalone mod (released separately): put your files in its music folder (see its docs). New songs and playlists show up in game on their own, with no restart needed.

Something went wrong. Where are the logs?

Every game session gets its own folder in UserData/OUAKModAPI/Logs/Sessions, with everything that happened (all.log), just the problems (errors.log) and a file per mod. A session that crashed is marked so at the next start. Logs from online play can hold player names, so check them before you share them.

How do I uninstall?

Delete the OUAK files from Mods (they start with OUAK), and ImGui.NET.dll and cimgui.dll from UserLibs. To remove MelonLoader too, follow its own uninstall steps.

Can I make my own mods?

Yes. The OUAK Modding API is meant for it: start from its example mod and the documentation. Small mods can even be "hot mods" that reload while the game runs.

Is this official?

No. It's an unofficial fan project, not affiliated with or endorsed by Bandai Namco Entertainment. You need your own copy of the game.
