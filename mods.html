REQUIRED

OUAK Modding API

Download v3.0.0 Source

The shared base every mod uses: the mod window, hotkeys, game events, stages and modes, saves, logging, asset replacement and hot mods. It also fixes the game's broken and unfinished features, and keeps your mods up to date by itself. Docs

MOD

OUAK Mod Menu

Download v1.5.0 Source

Single-player tools for speedrunning, TASing and messing around: give yourself any freebie, control the stage clock, jump to stages and modes, unlock things and back up your saves. Docs

MOD

OUAK Multiplayer

Download v2.2.0 Source

Roll through the story stages online together, with voice and quick chat, votes and the host in charge. Also Katamari Ball against CPU princes with custom rules, King Chances, Race and Target. Docs

MOD

OUAK Dash Bar

Download v1.0.0 Source

Shows how much Prince Dash you have left on the game's own dash gauge, which the game never shows, and counts down until it comes back. Turns rainbow during unlimited dash. Docs

MOD

OUAK Song Selector

Not released yet Source

Playlists that mix the game's music with your own songs (MP3, FLAC, M4A, WMA, WAV and more), updated as you add files, with play, pause, next, previous, loop and shuffle. Choose where each playlist plays. Docs
